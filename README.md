# 🚇 MetroGo — Metro + Cab Booking Application

MetroGo is a web-based Metro and Cab Booking application developed using Python and Streamlit.

The application allows users to select a metro route, book multiple tickets, optionally book a cab, calculate fares, generate a booking ID, and download a digital ticket.

## ✨ Features

- 👤 Passenger details
- 📅 Travel date selection
- 🚇 Metro station selection
- 🎫 Multiple ticket booking
- 💰 Automatic metro fare calculation
- 🚕 Optional cab booking
- 🚗 Mini, Sedan and SUV options
- 📍 Cab drop location
- 🎟️ Unique booking ID
- 📄 Downloadable digital ticket
- ✅ Input validation
- 🎨 Professional Streamlit interface
